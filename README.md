# 🚀 칸반 보드 태스크

# 기능 목록

## 칸반 보드 태스크 카드 만들기

### 제목

- [x] 제목을 인자로 받아 Text 컴포넌트 생성
- [x] 제목이 한줄이 넘어갈 경우 말줄임표로 표기
- [x] 제목이 null이거나 공백일 경우 "제목없음"으로 표기

### 설명

- [x] 설명을 인자로 받아 Text 컴포넌트 생성
- [x] 설명이 두줄이 넘어갈 경우 말줄임표로 표기
- [x] 설명이 null이거나 공백일 경우 아무것도 표시되지 않고 공간도 차지하지 않도록 구현

### 칩

- [x] 칩 내용을 인자로 받아 Text 컴포넌트 생성
- [x] 칩 내용이 null이거나 공백일 경우 아무것도 표시되지 않고 공간도 차지 하지 않도록 구현 
- [x] 한 칩안의 글자 수 제한(최대 5자)
- [x] 칩의 개수 제한(최대 5개)

### 담당자

- [x] 담당자가 null이거나 공백일 경우 "담당자없음"으로 표기
- [x] 담당자 이름이 한 줄이 넘어갈 경우 말줄임표로 표기
